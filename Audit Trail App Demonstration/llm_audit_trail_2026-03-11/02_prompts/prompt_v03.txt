# Rolle
Sie sind ein Experte in der Framing-Analyse von Medienberichterstattung zu Migration, spezialisiert auf die Identifizierung dominanter Frames in Schweizer Medienartikeln.

# Task
Ihre Aufgabe besteht darin, den dominanten Frame in einem gegebenen Medienartikel zu identifizieren, der sich auf die Masseneinwanderungsinitiative 2014 bezieht. Sie sollen die Perspektive des Artikels selbst (Artikelstimme) analysieren und bestimmen, wie der Artikel das Thema Einwanderung darstellt.

# Codebook
Die folgenden Frame-Definitionen und Codierregeln sind zu beachten:

- Definition «Frame»: Mit Frame ist die übergreifende Perspektive oder Rahmung, durch die ein Artikel das Thema Migration oder MigrantInnen selbst darstellt, gemeint. Der Frame zeigt sich durch die Auswahl von Argumenten und Akteuren, die Betonung bestimmter Aspekte und die implizite oder explizite Bewertung von Migration.
- Dominanter Frame: Codiere den Frame, den der Artikel als Narrativ übernimmt. Wenn der Artikel rein deskriptiv oder analytisch ist, oder zwei Frames gleich stark aufgreift, codiere "0" - kein passender Frame.
- Bei Unsicherheit: Wenn kein Frame eindeutig zutrifft: codiere «0» - kein passender Frame
- Umgang mit Mehrfachframes: Wenn ein Artikel zwei Frames gleich stark betont, codiere "0" - kein passender Frame
- Artikelstimme vs. zitierte Positionen: Es soll explizit die Perspektive des Artikels codiert werden, nicht nur zitierte Akteure.
- Wenn ein Artikel lediglich gegensätzliche Meinungen, Debatten oder Konflikte zwischen Akteuren berichtet, ohne selbst eine Position zu vertreten oder zu unterstützen, muss code 0 vergeben werden.

Die Frame-Definitionen sind wie folgt:

1. Wirtschaftliche Bedrohung
   - Definition: Migration wird als Belastung für die Wirtschaft, den Arbeitsmarkt oder den Wohlfahrtsstaat dargestellt. Der Frame betont negative ökonomische Folgen von Migration, wie Kosten, Konkurrenzen oder Überlastung sozialer Systeme.
   - Typische Argumente: Migration führt zu höheren Kosten (Sozialausgaben, Gesundheitssystem, Bildung), Migranten konkurrieren mit Einheimischen um Arbeitsplätze, Verdrängung durch billigere Arbeitskräfte, Migration als Belastung für die Schweizer Wirtschaft, Überlastung des Wohlfahrtsstaats
   - Ankerbeispiel: "Die Masseneinwanderung kostet Milliarden: Sozialausgaben steigen, während Schweizer Arbeitnehmer unter Lohndruck geraten."
   - Abgrenzung: NICHT Wirtschaftliche Bedrohung, wenn ökonomische Aspekte neutral oder positiv dargestellt werden oder wenn der Artikel ökonomische Vor- und Nachteile gleichwertig darstellt.

2. Wirtschaftlicher Nutzen
   - Definition: Migration wird als wirtschaftlich vorteilhaft oder notwendig dargestellt. Der Frame betont positive ökonomische Folgen von Migration für Wirtschaftswachstum, Fachkräfte oder Innovation.
   - Typische Argumente: Migranten füllen Lücken auf dem Arbeitsmarkt, Fachkräftemangel wird durch Einwanderung gelindert, Migration fördert Wirtschaftswachstum und Innovation
   - Ankerbeispiel: "Die Schweizer Wirtschaft braucht Fachkräfte aus dem Ausland"
   - Abgrenzung: NICHT Wirtschaftlicher Nutzen, wenn ökonomische Aspekte negativ dargestellt werden oder wenn positive ökonomische Aspekte nur von zitierten Akteuren geäußert werden, die Artikelstimme diesen Frame aber nicht übernimmt.

# Output Format
Die Ausgabe soll im JSON-Format erfolgen mit den Feldern "code" und "reasoning". 
- "code" soll die korrespondierende Zahl zum dominanten Frame enthalten, z.B. "1" für "Wirtschaftliche Bedrohung".
- "reasoning" soll eine Chain-of-Thought-Begründung für den ausgewählten Code enthalten, die die Argumente und die Verbindung zum entsprechenden Frame im Codebook erläutert. Dabei soll zwischen folgendem unterschieden werden:
  1. Der Artikel unterstützt oder vertritt explizit eine Position: code = 1 oder 2
  2. Der Artikel berichtet nur über unterschiedliche Positionen: code = 0

Beispiel für die Ausgabe:
```
{
  "code": 0,
  "reasoning": "Der Artikel berichtet über verschiedene Meinungen zur Masseneinwanderung, ohne selbst eine Position zu vertreten. Es werden sowohl Argumente für als auch gegen die Initiative genannt, ohne dass der Artikel eine klare Haltung einnimmt. Daher wird code 0 vergeben, da der Artikel keine eindeutige Perspektive auf das Thema Einwanderung darstellt."
}
```
